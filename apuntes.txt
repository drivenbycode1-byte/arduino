5.0 SERVOMOTOR:

Servo (servus en latín = sirviente) significa que un motor obedece ordenes, no gira libremente, tiene un angulo especifico (0 - 180 grados), se posiciona con precisión.
Tiene un motor dc y un potenciómetro interno, tiene un feedback (retroalimentación)
*Diferente del Stepper Motor que no gira con ángulos, o sea, da miles de vueltas y es extremadamente preciso. No tiene electrónica interna y necesita un driver. Tiene bobinas, no sabe donde está, uno debe decirle paso a apaso como moverse.

Potenciometro: tres pines - izquierda GND - medio Entrada analógica - Derecha 5V

Condensador (capacitores anglicanismo): almacena energía eléctrica en fomra de camp0o eléctrico. Unidad = Faradio
formado por dos placas que conducen la alectricidad y al medio un aislante dielectrico para que la electricidad no pase de un lado a otro. SI aplicacmos diferencia de potencial, las cargss negativos de un placa irán a la otra, estonces una placa queda con carga neta + y la otra -. pero laa carga total cerá 0 por que no se acumulan cargas electricas, solo se apsan de una placa a otra. Acumulan energia potencial electrica electromagnetica
Entonces al guardar energía por polaridad 

Ls idea de usar condensadores es por la caída de tensión, o sea, hay un pico muy alto de votaje al iniciar el servomotor

Todas las fuentes tienen resistencia interna, o sea R-interna. Esparte del material o cables, reguladores, necesita vencer la inercia, la friccción , cargar engranajes, etc. Entonces cuando el servo corre, necesita muchas corriente ya que parte de 0, esto se conoce como corriente de arranque o inrush current, siendo 3 a 5 veces mayor que la corriente del servo. Entonces como aumenta la corriente de golpe en una fuente con resistencia interna necesitamos algo que la modere (consdensador). Aquí entra la ley de Ohm pero la V es delta V, o la tensión quie se pierde. En VIR si I sube , delta V sube, entonces parte del voltaje se pierde (caída de tensión)
Supongamos:
- La fuente entrega 5 V
- Su resistencia interna es 0.2 Ω
- El servo pide un pico de 500 mA (0.5 A)
Entonces:
\Delta V=0.5\cdot 0.2=0.1\mathrm{\  V}
La línea baja de:
5.0\mathrm{\  V}\rightarrow 4.9\mathrm{\  V}
Si el pico es más grande (1 A), entonces:
\Delta V=1\cdot 0.2=0.2\mathrm{\  V}
La línea baja a:
5.0\mathrm{\  V}\rightarrow 4.8\mathrm{\  V}
Y si la resistencia interna es mayor (cables largos, mala fuente, USB débil), la caída puede ser mucho peor.

Entonces, si la fuente interna tiene resistencia va a abajar el voltaje que le va a allegar al servo, entonces el servo con menor voltaje (caida de tension) tendrá menor amperaje. Y todo esto sucede por que hay amperjae. Siempre que conectemos algo que requiera corriente/amperaje, el voltaje va a bajaar. o sea, si un aparato requiere mucha crriente, mediante la abse del VIR, el voltaje va a abjar, y si baja el voltaje, llega menos corriente al dispositivoy en consecuencia el dispositivo tendrá menos corriente.

Le llamamos un pico de corriente cuando el dispositivo (el servo en este caso) pide un x de corriente y en consecuencia de este pico, al no ser dado por la fuente ya que bajó su voltaje, habr,a un caidad de tension

El condensador no evita la caída de tensión “subiendo el voltaje”.
La evita entregando corriente para que la fuente NO tenga que entregar el pico.
El condensador no alimenta al servo todo el tiempo.
Solo entrega corriente en los picos para evitar que el voltaje caiga.
Entre picos, queda cargado a 5 V esperando el siguiente tirón.
Consume picos de corriente cada vez que:
- cambia de posición
- acelera
- frena
- corrige su posición interna
- lucha contra una carga
- compensa vibraciones
- su motor interno hace microajustes

- Q = C x V   --- Q = Carga almacenada (culombios) / C = Capacitancia (faradios) / V = Voltaje aplicado
El condensador no deja pasar corriente continua pero si deja pasar variaciones ráp[idas de voltaje.

5.4 SERVOMOTOR Servo con Easing:

Para lograr movimientos suaves usamos la interpolación o EASING, son movimientos que, podríamos decir, asemejan a los músculos.
supongamos que un servo se mueve de 0 a 90 grados, la interpolación lo hace pero con momentos espaciados (interpolados), o sea para llegar a 90 va de 5 grados en 5, divide el movimiento en pasos pequeños.
EASING = suavizar el movimiento (se puede acelerar y desacelerar). Vamos con el código:

#include <Servo.h> # librería para controlar servos.

Servo MiServo; # Instancia.

int anguloActual = 0;     // Donde está el servo ahora
int anguloObjetivo = 0;   // Donde queremos que llegue

void setup() {
  MiServo.attach(9);
}

void moverSuave(int objetivo) {  #moverSuave es un función que tiene como parámetro el int objetivo que será el ángulo al que se moverá el servo.
  anguloObjetivo = objetivo; # el valor de objetivo se guarda en anguloObjetivo.

  // Movimiento suave
  while (anguloActual != anguloObjetivo) {
    if (anguloActual < anguloObjetivo) anguloActual++;
    if (anguloActual > anguloObjetivo) anguloActual--;

    MiServo.write(anguloActual);
    delay(1);  // velocidad del movimiento
  }
}

void loop() {
  moverSuave(0);
  delay(1000);

  moverSuave(90);
  delay(1000);

  moverSuave(180);
  delay(1000);

  moverSuave(90);
  delay(1000);
}
