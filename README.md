# 🔥 Arduino & Electrónica — Mi laboratorio de aprendizaje

Este repositorio es mi espacio de práctica, experimentación y crecimiento técnico. Aquí guardo todo lo que construyo: desde ejercicios simples hasta proyectos completos que integran sensores, motores, lógica y creatividad.

Cada carpeta representa una etapa de mi proceso: aprender, fallar, corregir, mejorar y documentar.

## 🧩 ¿Qué encontrarás aquí?

### 🛠 Proyectos
Montajes completos con código `.ino`, archivos `.h`, configuraciones `.json`, fotos y notas. Cada proyecto tiene una historia y un objetivo.

### 📚 Ejercicios prácticos
Pruebas rápidas, experimentos, prototipos y pequeños scripts para entender cómo funciona cada componente.

### 📝 Apuntes
Mis notas personales: conceptos, comandos, ideas, diagramas, explicaciones y todo lo que me ayuda a avanzar.

### 📸 Fotos
Imágenes de montajes reales, conexiones, resultados y documentación visual.

## 🎯 Mi objetivo con este repositorio

- Construir un portafolio técnico sólido.  
- Documentar mi camino en electrónica aplicada.  
- Crear bases para proyectos más grandes.  
- Compartir mi proceso de aprendizaje de forma transparente.

## 🚀 Roadmap

- Añadir más proyectos con documentación completa.  
- Integrar diagramas en Fritzing.  
- Crear un índice general de proyectos.  
- Migrar algunos montajes a ESP32 y comunicación WiFi.

## 💬 Sobre mí

Creador de Driven By Code, apasionado por la electrónica, la programación y el aprendizaje continuo.
